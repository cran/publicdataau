Getting started with publicdataau

publicdata.au republishes Australian government open data that the publishers already release under open licences. It keeps every version at a URL that never changes, serves each one in twelve formats, and answers queries over the whole table. This package reads all of it from R. Every function takes a dataset’s slug, the part of its page’s URL after /d/.

library(publicdataau)

Query rows and totals

A version never changes once published, so a file can be kept and reused. Nothing is kept unless you ask, with cache = TRUE on a call or options(publicdataau.cache = TRUE) for every call; pd_cache_list() shows what is kept and pd_cache_clear() deletes it.

Query a version in place with dplyr

Every version has a DuckDB file. pd_tbl() attaches it over HTTPS and returns a table for ‘dplyr’; verbs become SQL that runs against the file, reading only the blocks they touch.

library(dplyr, warn.conflicts = FALSE)
pd_tbl("act-road-crashes") |>
  filter(crash_severity == "Fatal") |>
  count(lighting_condition, sort = TRUE) |>
  collect()

Versions, changes and provenance

Each release is compared with the one before it on the dataset’s key.

pd_changes("rba-money-market-daily")[, c("from", "to", "added", "removed", "changed")]

Reproducible work

An answer without a version comes from the newest one and changes when the publisher releases again. Pass a date from pd_versions() for one that never changes. pd_url() gives a fixed file address for another tool, such as a ‘targets’ pipeline with format = "url".

pd_url("act-road-crashes", "parquet", pd_latest("act-road-crashes"))
#> [1] "https://publicdata.au/d/act-road-crashes/v/2026-10-01/data.parquet"

Citing
